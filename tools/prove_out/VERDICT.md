# Coherence and sector: the verdict

**Coherence: NOT PROVABLE as the unattributed public readout.** The example
`0.847` has no identified producer, input record or scale in this repository.
We cannot explain that particular number to a customer or claim it measures
reliability, understanding, health or a physical device.

The code has several calculations called coherence. One combines two supplied
progress fractions into a policy score; it rises when either supplied fraction
rises. Another measures closeness between address coordinates; it falls as
those coordinates separate. These are different informational quantities.
Their implementations and scales also differ. Passing a calculation's tests
does not turn it into a calibrated confidence measurement.

**Sector: PROVED as a named ordinary address partition.** It is one of eight
routing labels selected by the address's theta coordinate. Moving across a
range boundary changes the label; changing other address fields does not.
The address version matters, and migration can change a label. This proves
address classification within the tested profiles, rather than text meaning.

A customer explanation could be: "This is the address's routing region. It
helps identify where the address belongs; it does not describe your words or
grant permission to another agent."

**Public display:** keep the generic coherence number and generic sector
readout off the website. The sector proof supports a clearly identified address
profile and ordinary address, if RADIX adopts that display. D5 still leaves
generic readout adoption undecided; this experiment changes no page or policy.
Sentinel codes and adjacency graphs differ between implementations, so those
cases cannot inherit the ordinary-partition proof. Consent remains separate.

A common coherence scale or unified sentinel/adjacency behavior needs an
explicit model proposal and owner decision. No such change was applied.
The [criteria](VERDICT_CRITERIA.md) and [validation](CX017_VALIDATION.md) give
the precise domains, counterexamples, commands, counts and reproduction limits.
