dependencies. Its `Bridge` samples actual `rpp-link-udp` probes and calls the
unchanged `rpp-steer::Selector`. Existing no_std core, traits, wire, crypto, and consent
rules are unchanged. It dispatches no application payload. See its README for mapping.

1000/800 kbps and does not relabel an estimate as independently measured capacity.

initially closed, reopen at/below lower and close above upper. No default policy.

ranking. Existing hold/margin governs return. Invalid batch/payload/clock inputs
fail before probes. Wrapper state commits only after successful sampling/choice;
physical UDP history can change during aborted I/O and is not rolled back.
