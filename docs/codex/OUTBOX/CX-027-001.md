The existing std-only UDP crate now also provides TcpAdapter, FallbackConfig
and FallbackAdapter, without changing public core/link traits or UDP grammar.
Fallback validates all numeric addresses as loopback before socket creation,
probes UDP once, then connects/probes TCP only if UDP is unavailable. Selection
precedes application/control sends and remains fixed. No application frame is
retried on another path or replayed after a partial/failed write. A complete
write means kernel acceptance, not peer/application delivery.

IMPOSED choices: reuse the existing crate and Lan/Wifi/Internet kinds; preserve
version/class envelopes and whole-envelope MTU1200/data1198; add only an outer
big-endian u16 length excluding itself (maximum TCP framing1202); require numeric
loopback on both accepted-stream endpoints and every fallback endpoint; retain
the existing nonzero <=250ms timeout cap; use one absolute frame/probe budget
across chunks, Interrupted calls and final completion; close stream I/O after
any frame error, including idle timeout/EOF; refuse resynchronization/reconnect.
Previously complete queued frames may still drain after closure, with control
recipient/verifier checks. The four-frame queue and 32-sample measurement model
are retained, as are exact nonce matching and bounded/quiet-reset echo rules.
No TLS/QUIC, cryptography, keys, tunnel, discovery, consent or admission is added.

Unlike UDP, TCP hides packet loss behind kernel retransmission and head of line
blocking. Readings represent application probe RTT/success, not raw IP loss.
A TCP frame error propagates and closes that session; UDP probe loss instead
returns an unavailable reading. TCP is refused even for tailnet addresses, and
accepted streams are supplied by the caller. No radio, board, internet, LAN or
firewall-blocking measurements are claimed: the blocked-UDP fixture is an OPEN
silent loopback socket, with a prebound TCP responder and an actual <2s check.
